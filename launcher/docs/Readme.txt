Clusterball Re-Enhanced
=======================

By Team ClusterForce - https://github.com/teamclusterforce/classic-clusterball

Clusterball (Daydream Software, 2000) playable again on today's PCs, without
changing the game:

- a Direct3D 11 renderer: sharp at the monitor's native resolution up to 4K,
  anti-aliasing, high-resolution textures, crisp menu and HUD text
- a launcher: server list, graphics settings, key bindings (WASD + mouse,
  mouse wheel), the game's manual built in, English and German
- optionally music and ball sounds from ClusterForce, a spiritual successor
  to Clusterball

Getting started
---------------
Start ClusterballCC.exe in the game folder (next to Clusterball.exe). When you
start the game from it, it installs and configures everything else.

Files Re-Enhanced adds to the game folder
-----------------------------------------
ClusterballCC.exe          the launcher
opengl32.dll               the Direct3D 11 renderer (installed by the launcher)
clusterball_d3d.ini        renderer settings (written by the launcher)
clusterball.ini            launcher settings
textures\hd, textures\font high-resolution textures and the sharp font
Music\CF 2026\             ClusterForce music, when switched on
clusterforce\              ball sounds from ClusterForce, when chosen
Clusterball Re-Enhanced - *.txt   this readme, the license and the notice

The original game files are not changed.

Trouble?
--------
Log=1 in clusterball_d3d.ini makes the renderer write compat.log and d3d.log.
Questions: the forum at https://clusterball.de/board
Problems with Re-Enhanced: https://github.com/teamclusterforce/classic-clusterball
